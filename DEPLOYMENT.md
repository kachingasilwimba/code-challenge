I would containerize the FastAPI service and ingestion scripts (Docker) and deploy them on Amazon ECS Fargate. The API would run as a Fargate service behind an Application Load Balancer, with configuration (DB URL, secrets) stored in AWS Secrets Manager / SSM Parameter Store and logs sent to CloudWatch Logs. I would store the raw wx_data files in Amazon S3 and use Amazon RDS (PostgreSQL) for the production database (better concurrency/backups than SQLite). The ingestion + stats calculation would run as a scheduled Fargate task triggered by Amazon EventBridge Scheduler (cron). For CI/CD, I’d use GitHub Actions to build/push images to Amazon ECR and update the ECS service/tasks.
